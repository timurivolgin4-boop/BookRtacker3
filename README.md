Описание программы
Currency Converter — это графическое приложение (GUI) для быстрой конвертации валют. Программа использует внешний API для получения самых актуальных курсов обмена и позволяет вести историю операций с возможностью сохранения и загрузки данных в формате JSON.

Как получить API-ключ
Для работы приложения необходим бесплатный API-ключ от сервиса exchangerate-api.com. Без него программа не сможет получить данные о курсах валют.

Перейдите на сайт exchangerate-api.com.
Зарегистрируйтесь для получения бесплатного доступа.
В личном кабинете скопируйте ваш уникальный API Key.
Откройте файл main.py в любом текстовом редакторе.
Найдите строку API_KEY = "YOUR_API_KEY_HERE" (в самом начале файла).
Замените текст YOUR_API_KEY_HERE на ваш скопированный ключ.
Сохраните изменения в файле.
Как использовать программу
1. Конвертация валюты
В левом выпадающем списке выберите валюту, которую вы хотите обменять («Из»).
В правом выпадающем списке выберите валюту, которую хотите получить («В»).
Введите сумму для обмена в поле «Сумма». Используйте только цифры и точку для дробной части (например, 100.50).
Нажмите кнопку «Конвертировать».
Результат вычисления появится под кнопкой. Операция будет автоматически добавлена в таблицу истории ниже.
2. Работа с историей операций
Под основным блоком конвертации находится таблица со списком всех выполненных операций.

Сохранить историю в JSON: Нажмите эту кнопку, чтобы записать все операции из текущей таблицы в файл conversion_history.json. Это полезно для резервного копирования.
Загрузить историю из JSON: Нажмите эту кнопку, чтобы заполнить таблицу данными из ранее сохраненного файла conversion_history.json.
Очистить историю: Нажмите эту кнопку для удаления всех записей из текущей таблицы. Программа запросит подтверждение перед удалением.
