# Expense Tracker

## Автор: [Иволгин Тимур Владимирович]
## Описание программы:
Простое кроссплатформенное приложение для учёта личных финансов. Позволяет добавлять расходы с указанием суммы,
категории и даты. Реализованы функции фильтрации по категории и дате (точное совпадение), подсчёта общей суммы за выбранный период,
а также сохранение и загрузка данных в формате JSON.

## Как использовать:
1. Запустите `main.py` с помощью Python 3.
2. Заполните поля: Сумма (число), Категория (выпадающий список), Дата (формат ГГГГ-ММ-ДД).
3. Нажмите «Добавить расход».
4. Для расчёта суммы за период — введите даты в поля «С» и «По» и нажмите соответствующую кнопку.
5. Для фильтрации — используйте выпадающий список категорий или введите дату.
6. Данные можно сохранить в файл `expenses.json` или загрузить из него.
